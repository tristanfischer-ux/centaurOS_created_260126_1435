# Tasks Directory

This directory contains files for tracking work and capturing lessons learned.

## Files

### `todo.md`
Current task tracking. Use this to:
- Plan multi-step work
- Track progress through checklists
- Document decisions and context
- Enable work resumption after interruptions

### `lessons.md`
Captured patterns and mistakes. Use this to:
- Record lessons from corrections
- Document recurring patterns to avoid
- Build institutional knowledge
- Review at session start

## Usage

### At Session Start
1. Check `todo.md` for any in-progress work
2. Review `lessons.md` for relevant patterns
3. Check `../AGENT_HANDOVER.md` if continuing from another agent

### During Work
- Update `todo.md` as you complete steps
- Add notes for context and decisions
- Mark items complete with `[x]`

### After Corrections
- Add entry to `lessons.md`
- Include: what happened, why, lesson, prevention

### After Completing Work
- Add review section to `todo.md`
- Consider lessons worth capturing
- Archive completed tasks to Previous Tasks section
