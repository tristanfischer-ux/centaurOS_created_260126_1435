1. Glyph Catalogue — 21 Explicit Radicals

Each glyph shown at 12 px (functional minimum) and 64 px (display size). All glyphs are inline SVG — monoline, greyscale-safe, no gradients, no emoji.

solid_state_of_matter is implicit by default — rendered only when explicitly invoked (phase-change materials, thermal fuses, eutectic alloys). Not in the standard palette; defined at the end of this section.

2. Modifier Taxonomy — 15 × 5 × 4 = 300 Combinations

New glyphs must differ on at least 2 of the 3 layers from any existing glyph. This prevents palette exhaustion at 60+ radicals.

3. Quadrant Rules — System B (function-top, material-bottom)

SlotPositionSemantic

Empty quadrants render a faint dash placeholder (not blank dead space). Compression to 2×3 grid for 5–6 radicals. Full fall-through rules in QUADRANT-RULES.md.

4. Grammar Conflict Rendering

Conflicts render between character squares — never on them. Radical icons stay legible when diagnosing the conflict. Coloured borders are a secondary signal only (colour-blind safe).

5. Product Paragraphs — BESS, Heat Pump, Drone

Default view: sentence-cluster summary showing the dominant radical icon. Click any cluster header to expand to full quadrant view. All 3 products use the same radicals as the week-2 to week-4 decompositions for direct comparison.
