## Gotchas discovered
- **TypeScript `as Record<string, unknown>` pattern**: When casting AutopilotState, must use `as unknown as Record<string, unknown>` — single cast fails because types don't overlap
- **ScoreBreakdown interface**: Adding a new scoring dimension requires updating BOTH the scoring logic AND the interface AND all default objects that create ScoreBreakdown values (forge-shortlist.ts was missed initially)
- **AutopilotState interface gaps**: The interface is missing several runtime fields (status, attempts, total_resets, council_diagnosis). These are accessed via type casts. Should be added to the interface in a future cleanup.
- **Pre-existing type errors**: gate-3.ts (4 errors), tasks.test.ts (4 errors), cad-lab-projects.ts (1 error), plan/ files (multiple) — these existed before our changes
