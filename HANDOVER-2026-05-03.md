## Gotchas discovered
- **Scoring summariser mismatch**: `summariseModules` expected `material/dimensions/specifications/cost` but modules use `keyParts/specs/estimatedMassKg/purpose`. Judges received nearly empty summaries → 4-5/10 on everything.
- **Anthropic was NOT removed from CAD-Lab**: Specialist tiers were swapped but CAD-Lab's `callClaude` and `claude-opus-4-7` defaults were left unchanged. The swap was supposed to cover everything but didn't.
- **No code enhancer existed**: The council diagnoses problems but nobody fixes code between retries. The specialist just re-rolls the same prompt. This was the missing piece for the quality loop.
- **`second-opinion_ask_alt_llm` MCP tool times out**: Use direct OpenRouter curl calls instead — same API, reliable.
- **`makeDeepSeekModel` calls DeepSeek directly** (api.deepseek.com), not OpenRouter. The Grok model uses OpenRouter. Both work but different endpoints.
