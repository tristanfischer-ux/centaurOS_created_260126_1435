## 3. Hiring Process

### For All Roles

1. **Define**: Write job spec with clear requirements and compensation
2. **Source**: Personal network first, then targeted platforms
3. **Screen**: CV review + 15-min intro call
4. **Assess**: Paid trial task (real work, compensated)
5. **Interview**: Technical + culture fit (1 hour)
6. **Reference**: 2 references minimum
7. **Offer**: Clear terms, start date, probation period

### Compensation Philosophy
- Competitive market rates for remote UK roles
- Equity consideration for early hires (if converting to full-time)
- Transparent about stage (bootstrapped startup)
- Performance-based bonuses tied to product metrics

## 5. Pre-Hire Checklist

- [ ] Employment contract template ready (see Legal/contract-templates.md)

- [ ] PAYE setup with HMRC (if employing)

- [ ] Onboarding documentation (codebase access, tools, accounts)
- [ ] IP assignment clause in all contracts
- [ ] Decide: contractor vs. employee status (IR35 implications)
