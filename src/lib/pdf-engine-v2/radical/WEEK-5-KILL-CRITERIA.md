# Week 5 Kill Criteria — non-negotiable

These are committed BEFORE Week 5 decomposition begins. This is the universality FINAL test.

1. **Per-product radical reuse** — each product ≥80% radical reuse against post-Week-4 library (slightly relaxed from Week 4's 85% — niche classes have legitimate domain edges)

2. **Per-product radical growth cap** — each product ≤4 new radicals (so total cap ≤12 new across the 3 products). Library should be at 20 + ≤12 = ≤32 after Week 5

3. **TOTAL radical count after Week 5** — ≤22 if convergence is real (council predicted 30-50; we're testing whether reality is even tighter than 22). If radicals balloon to ≥25, universality is partial.

4. **Coverage** — every product BoM at 100% decomposition

5. **Cross-batch character reuse** — at least 50% of niche-class characters appear in 2+ products (recalibrated downward from Week 3's 50% threshold — niche classes legitimately have unique characters; this is a sanity check, not a kill condition for sub-50%)

If radicals stay ≤22 (KC3 PASS): universality empirically proved. Recommend v1 production migration dispatch.
If radicals go 22-25: universality holds but niche classes have a small edge.
If radicals exceed 25: structural failure — the architecture has a niche blind spot.
